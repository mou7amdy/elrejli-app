# الرجلي — دليل الإعداد والنشر

اتبع هالخطوات بالترتيب. كلها مجانية.

## 1) إنشاء حساب Supabase (قاعدة البيانات + تسجيل الدخول)

1. روح لـ https://supabase.com و سجّل حساب (بإيميلك)
2. اضغط **New Project**
3. اختار اسم للمشروع (مثلاً rajli) وكلمة سر لقاعدة البيانات (احفظها)
4. اختار المنطقة الأقرب (مثلاً Europe West)
5. استنى دقيقتين حتى يتجهز المشروع

## 2) تشغيل قاعدة البيانات

1. من القائمة الجانبية، افتح **SQL Editor**
2. اضغط **New query**
3. افتح ملف `supabase/schema.sql` من هذا المشروع، انسخ محتواه كامل، والصقو في المحرر
4. اضغط **Run**
5. لازم يطلع "Success" بدون أخطاء

## 3) تفعيل تسجيل الدخول بالكود (Email OTP)

1. من القائمة الجانبية: **Authentication** → **Providers**
2. افتح **Email**
3. تأكد إن **Enable Email provider** مفعّل
4. من **Authentication** → **Emails**، افتح قالب **Magic Link / OTP** وتأكد إنه يرسل كود (Supabase يرسل كود من 6 أرقام تلقائيًا مع `signInWithOtp`)
5. اختياري: بدّل اسم المرسل من **Authentication** → **URL Configuration**

## 4) الحصول على مفاتيح الربط

1. من القائمة الجانبية: **Settings** → **API**
2. انسخ:
   - **Project URL**
   - **anon public key**
3. في مجلد المشروع، سمّي ملف `.env.example` إلى `.env`
4. حط القيم:
```
VITE_SUPABASE_URL=القيمة اللي نسختها
VITE_SUPABASE_ANON_KEY=القيمة اللي نسختها
```

## 5) تجربة التطبيق محليًا (اختياري، تحتاج Node.js مثبت)

```bash
npm install
npm run dev
```
يفتح على `http://localhost:5173`

## 6) تسجيل الدخول أول مرة وتصيير نفسك أدمن

1. شغّل التطبيق (محليًا أو بعد النشر) وسجّل دخول بإيميلك
2. رجع لـ Supabase → **Table Editor** → جدول `profiles`
3. تلقى صف بإيميلك، عدّل عليه يدويًا:
   - `is_admin` → `true`
   - `status` → `approved`
4. رجع للتطبيق (أو حدّث الصفحة) — بش تلقى أيقونة الأدمن 🛡️ فوق فالصفحة الرئيسية

من هالنقطة، أي شخص آخر يسجل دخول رح يبان طلبو عندك في لوحة الأدمن باش تقبلو.

## 7) النشر على الإنترنت (مجانًا عبر Vercel)

1. ارفع هذا المشروع على GitHub (حساب جديد أو موجود، repo جديد، ارفع كل الملفات)
2. روح لـ https://vercel.com وسجّل دخول بحساب GitHub
3. **Add New Project** → اختار الـ repo متاعك
4. فتحت خانة **Environment Variables**، ضيف:
   - `VITE_SUPABASE_URL`
   - `VITE_SUPABASE_ANON_KEY`
   (نفس القيم من ملف `.env`)
5. اضغط **Deploy**
6. بعد دقيقة، يعطيك رابط زي `rajli.vercel.app` — هذا رابط التطبيق النهائي

## 8) إضافة التطبيق للشاشة الرئيسية (بدل تحميله من App Store)

على آيفون:
1. افتح الرابط من Safari
2. زر المشاركة (Share) → **Add to Home Screen**

على أندرويد:
1. افتح الرابط من Chrome
2. القائمة (⋮) → **Add to Home screen**

التطبيق بش يبان بأيقونة عادية ويفتح بدون شريط المتصفح (بفضل ملف الـ PWA manifest المضاف).

## ملاحظات مهمة

- **الإشعارات هنا داخل التطبيق فقط** (in-app) — تبان في جرس 🔔 لما يفتح التطبيق. لو حبيت push حقيقي يوصل والتطبيق مسكّر، هذا يحتاج خطوة إضافية (Firebase Cloud Messaging) نقدر نضيفوها بعدين
- كل خانة عندها موافقة منفصلة — أي شخص يقدر يطلب الانضمام لخانة وحدة أو أكثر، وإنت (كأدمن) تشوف كل الطلبات في لوحة الأدمن
- حساب الأدمن الأول تعطيه لروحك يدويًا من قاعدة البيانات (خطوة 6) — بعدها تقدر توافق على البقية من داخل التطبيق نفسه
